# Alberto-Clock-website# Alberto Clock

Alberto Clock is a premium online store for luxury watches and wall clocks. Browse collections, add items to your cart or wishlist, and get watch suggestions from the built-in AI bot.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Features

- Splash screen and page loader
- Men's, Women's, and Wall Clock collections
- Shopping cart, wishlist, and Buy Now
- Offers and discount codes
- Product gallery and FAQ
- AI chat bot for watch suggestions
- Responsive design.
